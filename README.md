# GPT 6 Astra as an Embodied Policy

Production static report by Jiayi Su, Yixin Zheng, Mi Yan, Li Yi, Zhizheng Zhang, and He Wang.

- Open `index.html` through an HTTP server. English is the default; use the language button or `?lang=zh` for Chinese.
- [Source code and citation](https://github.com/anonymous-report-421/eval-of-gpt-6-astra-as-policy).
- To serve with GitHub Pages, select the `main` branch and repository root under Settings → Pages.
- Serve video files with byte-range support to enable seeking. No Node or model backend is required in production.

Videos were rendered offline from recorded observations and action receipts, with task prompts and hybrid command-direction arrows. Results and frame ranges are unchanged. The [RoboLab gallery](robolab-gallery.html) adds 150 original recordings across three methods and ten tasks. Its manifest records every media hash. RoboLab MP4s are hosted in this repository's video release; posters and the gallery page are part of the static site. Project-owned code is MIT; third-party rights and font licenses remain unchanged. No credentials, raw model sessions, or private annotations are included.
